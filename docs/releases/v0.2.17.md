# v0.2.17

## Highlights

- Fix webpage model selection getting stuck when a closed Claude menu retains selected options in the DOM.
- Let a native webpage send wait safely for a temporarily disabled send control instead of failing before submission.
- Recheck the server branch before each click and retain pending when identity or readiness is uncertain; no duplicate click or channel retry is introduced.

## Upgrade

- Install this version with the published installer. Existing aliases, pending state and API configuration are unchanged.
- Reconnect direct hosts after installation so they load the new runtime.
