# v0.2.15

## Highlights

- `clearReconnectMarker` closes the remaining stat→unlink race: the marker identity is re-verified immediately before removal, so a swapped or oversized marker is never silently deleted.
- `--notes-file` content is scanned by `assertPublishableContent` before it reaches a Gitea Release body.

## Upgrade

- No configuration migration is required. `v0.2.14` remains installed and immutable; upgrade to `v0.2.15` when you want the tightened marker boundary and the notes-content gate.

## Added / Changed / Fixed

- `clearReconnectMarker` in `src/release/install-fs.mjs` re-checks the marker (dev/ino/size) after opening it and before `unlink`.
- `loadReleaseNotes` in `scripts/publish-gitea-release.mjs` rejects sensitive content and sandbox home paths via `assertPublishableContent`.

## Verification

- `npm test`: 747 offline tests pass.
- `npm run build:release`, `npm run build:plugin`, `npm run verify:plugin`, `npm run verify:structure`, `git diff --check` pass.
- Local HTTP fixture verifies Release creation body, asset allowlist, checksums and token redaction; no live Gitea publication or host reconnection is claimed.

## Rollback

- `bash install.sh --rollback` returns to the verified `v0.2.14` release; sessions, pending state and host configuration are unchanged.
