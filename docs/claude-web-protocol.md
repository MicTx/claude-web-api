# Claude 网页通道机制摘要

> 公开净化版。本文描述本项目观察到的机制边界，不是 claude.ai 官方文档，也不是稳定公共 API 规范。页面实现、选择器与请求形状可能随时变化；不要把本文当作接口兼容性承诺或操作账号的授权。

## 适用范围

本项目连接本机 loopback 上的 Chrome 调试端口，使用操作者自己的已登录会话，在自有后台标签页内完成一次咨询。请求由页面上下文发出，沿用浏览器的认证与网络身份；Node 侧不复制 cookie、不伪装 TLS 指纹，也不保存临时凭据、组织标识或会话 UUID 到仓库文档。

网页端至少存在两类需要区分的会话形态：

- 旧式纯文本会话：使用 JSON REST 提交，SSE 返回分块事件；当前实现累计文本，而不是向调用者逐 token 转发。
- 升级后的网页会话：使用网页原生编辑器与页面自有的提交/时间线机制；附件和生成文件也走这条路径。

升级后的网页实现使用二进制协议，且没有公开 schema。本项目不把它包装成可依赖的 SDK：能由页面原生控件完成的操作不重放私有 RPC，旧式 JSON 发送结论也不能自动套到升级会话上。

## 一次回复的生命周期

旧式 SSE 路径中，服务端按序发出开始、内容块、增量、结束与用量事件。客户端按内容块索引累计正文，记录回复的终止原因，并在流正常结束时确认完成。缺少结束事件、内容截断或超时都保留为不完整状态；`message_delta`、`message_stop` 与 `API_STREAM_INCOMPLETE` 是不同层的信号，不能互相替代。用量快照也不等于本地硬预算。

连续追问依赖网页服务端当前分支的父指针：新消息接在已完成的回复之后，而不是把本地猜测的文本链当作权威历史。别名保存的是定位这条分支所需的最小元数据；prompt 与回复正文不进入普通状态目录。

发送不确定时，先只读回读权威历史，确认原 human 消息与已完成 assistant 回复成对出现，再清除本地 pending。历史不足、摘要不一致或页面状态冲突时保留 pending，不重发、不改写原问题，也不把一次本地超时当作服务端失败。`PROMPT_MISMATCH` 表示恢复正文与本次规范化摘要不一致；这类请求在打开浏览器前拒绝，pending 保持不变。终止与完整是两个状态：`complete: false` 可表示回复已结束但内容被截断，不能据此推断发送结果。

## 附件、草稿与回拉

附件上传是显式动作。当前只接受用户选择的 PNG 与 UTF-8 `.js`；PDF 与把 PDF 文件头伪装成代码的附件在上传前拒绝，目录、仓库与 import 图不展开。历史遗留的 PDF pending 仍可读取并对账，但不能作为恢复草稿提交；聊天返回的 PDF 文件仍可按产物标识下载。

原生上传回执在页面 `fetch` 的响应阶段按本标签页、主 frame、方法与同源路径有界拦截；不依赖全页响应体缓存。挂起请求必须以独立的释放动作结束，重定向中止，释放失败拒绝提交；退出拦截前等待在途处理收束。回执到达比草稿持久化更早：草稿可能先显示临时 blob，稍后才更新为带服务端文件身份的图片记录。提交前只读有界等待完整身份核对；草稿正文、附件清单、大小、类型或文件身份不符都是永久冲突，超时则保留 pending 而不重传。

显式恢复只复用与原始正文一致、且每个二进制文件身份都已记录的草稿；不重新选文件、不重复输入，也不覆盖其他文字。恢复正文含替换字符 `U+FFFD` 时在打开浏览器前拒绝，兼容网页双换行不等于可以改写字节。版本升级后的固定指导块不保证重建旧正文，因此契约版本变化时须提供原次完整正文。

下载按会话返回的文件标识刷新服务端元数据并写入受控输出根；不覆盖现有文件，不执行、打开或解压，拒绝任意 URL。调用者仍须在本地核对实际内容、MIME、大小和 SHA-256。

## 生成文件与未核验边界

网页回复中的生成文件可以有多种呈现形态。实现只把「同轮先写单文件、随后首次发布同一文件、内容满足 LF 换行与纯 ASCII」的窄情形视为原件可回拉；其余发布、改版、多文件、类型化产物和非 ASCII 页面均标为原件导出未核验、不支持。查看页的改写预览不是原始字节；服务端元数据声明也不是逐字节证明。

本项目不为取得文件而放宽分享权限、绕过访问控制或把未证明的路径伪装成支持。文件来源、当前分支、工具调用顺序与内容约束必须一起核对；任何一项缺失就停止，并返回明确的未核验状态。

## 维护原则

网页接口不是稳定公共契约。怀疑实现漂移时，应在隔离账号与自有后台页中有界复核请求形状、事件序列、页面控件和权威历史；先更新实现回归与文档，再改变默认发送路径。不要把一次样本观察写成普遍结论，也不要把私有标识、账号细节、临时凭据或采样记录写入公开文档。
