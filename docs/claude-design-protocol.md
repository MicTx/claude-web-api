# Claude 生成文件与设计型产物机制摘要

> 公开净化版。本文只说明本项目对生成文件、设计型产物与「原件」证据的通用边界；它不是 claude.ai 官方文档，不提供私有接口、账号操作或实验流程，也不宣称某个产品类型已经完整支持。

## 本文回答什么

网页回复有时不只给文本，还会生成可查看的页面或文件。读者最关心的是：哪些字节能被当作原件回拉，哪些只能算查看页预览，哪些证据不足以做出判断。本文把这三件事分开；具体命令和当前支持范围以[使用说明](usage.md)为准。

本项目不把「页面上出现过一个预览」等同于「拿到了原始文件」。查看页常会注入运行时脚本、改写 HTML 或按版本路径返回派生表示；服务端元数据里的版本、大小和摘要也只是声明。原件证据要求来源字节可核对，且与当前会话、当前分支和明确的发布动作关联。

## 三个证据层

**声明**：回复或文件元数据列出版本、路径、大小、摘要。它能帮助定位候选，不能证明文件字节可读取，也不能证明这些字节没有被查看层改写。

**投影**：只读采证把请求来源、页面作用域、MIME 与状态投影成脱敏摘要。query、header、cookie、临时凭据和响应正文不进入投影；候选缺失只表示证据不足，不表示服务故障或文件不存在。

**原件**：从权威会话历史中定位明确的写文件动作，再按同轮、单文件、首次发布、路径一致与内容格式约束核对实际字节；下载后仍由调用者独立计算 SHA-256。只有这一层才能支持「原件可回拉」。

三层互不替代。即使声明与投影匹配，没有读回并核对字节，也仍是 `claim` 而非原件证据。

## 保守的候选规则

实现只接受由当前标签页、当前主 frame 与预期资源路径产生的有界候选。跳转、重复、缓存、service worker、跨 frame、作用域不明或事件不完整时返回未核验，不自动切换到更宽松的通道，也不重复采集。响应体只在大小上限内临时读取；浏览器缓存驱逐或正文不可得时停止并报告。

这些规则是安全边界而非兼容性证明。真实页面可能把请求放进 worker 或子 frame，也可能在监听器建立前发出事件；一个「未捕获」结果只能说明当前观察范围没有覆盖，不能据此声称服务不支持。任何规则放宽都先要有隔离样本、实现回归与明确授权，不能因为一次失败就默认放行。

## 设计型产物为何不自动归类

「Design」这类产品形态可能依赖特定页面控件、发布类型或版本机制；控件名、工具名或页面标题都不足以证明真实类型。实现把类型未知记为未知，不把唯一发布推断成设计型产物，也不在类型未核验时启动续改。多文件、改版、重新发布和类型化产物都留在未支持集合，避免用脆弱选择器制造成功假象。

不确定创建、提交或发布时保留 pending，不自动补发；自建标签页在无法确认草稿为空时保留并报告，避免误删用户内容。失败结果保留当时观察，不用事后读到的状态悄悄改写先前的结论。

## 公开边界

- 不记录账号、组织、会话或产物 UUID，也不保存临时凭据、cookie、认证 query 或内部实验与审批材料。
- 不把私有探针、一次性采样记录或未公开的实验入口写成公共接口。
- 不因为代码里留有实验入口，就声称该产品类型已经通过验收；离线测试只证明解析与状态机，不证明线上服务形态。
- 不为导出文件更改分享权限、绕过 403 或访问非当前会话的资源。
- 任何新采证都需要新的明确授权、最小作用域和可证伪的成功判据；本文不构成授权。
